# Prior Code References

Copy previous repositories or baseline implementations here when they are useful
for comparison or reconstruction.

For each copied codebase, add a small README with:

- What the code was used for.
- Which results or modules are reliable.
- Which parts are obsolete or experimental.
- Any required environment assumptions.

Do not treat files in this directory as active source for the new implementation.
Reusable code should be intentionally ported into `src/` with tests.
