# Working Notes

Use this directory for compact notes that help guide the paper and experiments.

Useful files to add:

- `paper_positioning.md`: novelty boundaries and related-work framing.
- `experiment_matrix.md`: planned experiments, metrics, baselines, and status.
- `reviewer_failure_modes.md`: issues from prior reviews and how to address them.
- `reference_index.md`: short index of papers and prior code.

Keep notes concise and update them when assumptions change.
