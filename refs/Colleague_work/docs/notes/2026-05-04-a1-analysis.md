## 1. Framing 확정 — (B) "Atomic PMF에 대한 algebraic unification"

세 framing을 비교한 끝에 (B)를 채택.

| Framing | 메시지 | 약점 |
|---|---|---|
| (A) Multi-class generalization | "Shukla이 future work로 남긴 multi-class를 푼다" | Multi-class DP를 직접 구현하면 우리 conv와 동치 → trivial extension 비판 위험 |
| **(B) Atomic PMF algebraic unification** | "Bernoulli/categorical/signed/multiplicity 모두 동일 conv-on-atomic-PMF의 instance. Conv view는 atom의 algebraic 구조를 통일." | 검증 부담: 단일 task가 아니라 다중 case의 통합성을 보여야 함 |
| (C) Implementation upgrade | "GPU batching / 구현 단순화" | Cosmetic — main contribution 강도 부족 |

(B)의 본문 뼈대:
- §3 도입에서 SIMPLE Prop 1 (binary $z_i \in \{0,1\}$, $P(\sum z_i = s)$ in $O(nk)$)이 binary atom의 special case임을 명시.
- Multi-class atom으로 일반화한 DP를 직접 짜면 conv와 동치임을 short proposition으로 본문에 둠 — 이로써 reviewer의 "DP를 generalize하면 자동으로 conv 아니냐" trivialization을 우리가 통제.
- Conv view의 contribution은 "DP를 extend"가 아니라 "atomic PMF의 algebraic 구조에 대한 abstraction". Bernoulli, categorical $K{+}1$, signed $\{-1,0\}$/$\{0,+1\}$, multiplicity $\{0,m_i\}$가 모두 kernel choice로 통합됨.

## 2. Lineage 정정 — Shukla DP의 base는 SPL이 아니라 **SIMPLE**

이전 작업 노트에서 "Shukla DP의 base = SPL (Ahmed NeurIPS 2022)"이라고 잡고 있었으나, Shukla 본문 `:1086`의 Proposition proof와 `references.bib`의 `simple2023` 키를 직접 확인한 결과:

- `simple2023` = **Ahmed/Zeng/Niepert/Van den Broeck, "SIMPLE: A Gradient Estimator for k-Subset Sampling", ICLR 2023** (arXiv 2210.01941, GitHub UCLA-StarAI/SIMPLE).
- SIMPLE Proposition 1: 독립 binary $z_i \in \{0,1\}$의 합 $P(\sum z_i = k)$를 $O(nk)$ DP로 계산.
- Shukla은 이 binary DP를 **그대로 import**. 그래서 Shukla DP = SIMPLE Prop 1의 application.

SPL (Ahmed/Yousri/Niepert/Vergari/Van den Broeck, NeurIPS 2022, arXiv 2206.00426)은 **다른 논문**:
- Generic propositional logic constraint를 probabilistic circuit으로 compile해서 conditioning.
- 형식: $p(y|x) = q_\Theta(y|f(x)) \cdot c_K(x,y) / Z(x)$ where $q$는 PC, $c_K$는 constraint circuit (SDD/OBDD compile).
- **Binary label vector $y \in \{0,1\}^L$만 다룸**. Count constraint 자체는 native 미지원 — 다루려면 "$\sum y_i = s$"를 SDD로 별도 컴파일해야 함.
- 본문 예시: HMLC, pathfinding, preference learning — 모두 binary.

**메모리에 reference로 저장됨**: `reference_simple_vs_spl.md`.

### 본문에서 lineage 기술 방향

§3 introduction 뼈대:
> "Shukla 2023 reformulated count-based weakly supervised learning as a single objective on the marginal $P(\sum_i z_i = Y)$, importing SIMPLE Proposition 1 (Ahmed et al. 2023) as the tractable computation primitive for binary $z_i \in \{0,1\}$. We observe that this marginal is a 1D convolution of atomic PMFs, $P_Y = \mathbf d_1 * \cdots * \mathbf d_N$, with Bernoulli atom $\mathbf d_i = [1-p_i, p_i]$. The convolution view is invariant to atom shape — switching to categorical, signed, or multiplicity atoms requires only a kernel-length change, generalizing the count-WSL framework beyond binary as Shukla suggested in their Conclusion."

이 한 단락이 (B) framing 핵심 메시지.

## 3. SPL을 baseline에서 제외하는 사유 + 본문 기술 방향

**제외 결정**: SPL은 multi-class atomic PMF를 native로 다루지 않음 → MNIST-sum/SVHN-sum/UltraMNIST의 직접 baseline으로 부적합. 구현 부담도 (SDD compilation 필요) 큰데 비교 결과의 의미는 약함.

### 본문에서 SPL을 어떻게 다룰 것인가 — 4가지 경계 명확히 (Related Work에 한 단락)

다음 문장 구조를 본문에 둘 것 (영어 draft):

> **"Semantic Probabilistic Layers (SPL; Ahmed et al. 2022)** generalize tractable probabilistic inference under arbitrary propositional logical constraints by compiling the constraint into a probabilistic circuit and taking a vtree-compatible product with the predictive distribution. While SPL provides a unifying view of constraint conditioning, three differences make our convolutional treatment a distinct contribution.
>
> *First, target structure.* SPL formalizes binary label vectors $y \in \{0,1\}^L$ under arbitrary propositional constraints; multi-class atomic variables $z_i \in \{0,1,\dots,K\}$ are not in scope. Encoding our count constraint $\sum_i z_i = Y$ for $K{+}1$-ary $z_i$ in SPL would require introducing one-hot indicator variables and a mutual-exclusion subcircuit, then compiling the count constraint into an SDD — a per-$K$ compilation that does not capture the algebraic uniformity we expose.
>
> *Second, atom-shape uniformity.* The conv view treats Bernoulli, categorical, signed, and multiplicity atoms with a single algorithm parametrized by kernel choice; binary, multi-class ordinal, signed, and multiplicity counting fall out without circuit recompilation. SPL's tractability cost scales with $|q| \cdot |c|$ for a separately compiled constraint circuit per atomic variable schema.
>
> *Third, base lineage.* The binary count probability that Shukla 2023 imports is from SIMPLE (Ahmed et al. 2023), a separate work that gives an $O(nk)$ DP for $P(\sum_i z_i = k)$ over binary $z_i$. Our work generalizes that count primitive — not SPL's circuit conditioning — by atomic-PMF algebra.
>
> SPL therefore stands as the broader probabilistic-circuit constraint-conditioning framework, while PCA targets the count-aggregation case directly with atom-shape generality."

### 위 단락의 핵심 4축

1. **Target structure 차이**: SPL은 binary label vector, PCA는 multi-class ordinal atom.
2. **Compilation cost**: SPL은 atom schema마다 SDD 재컴파일, PCA는 kernel choice 한 줄.
3. **Base lineage 정정**: Shukla DP의 base는 SPL이 아니라 SIMPLE — paper 작성 시 reviewer가 SIMPLE/SPL을 혼동하지 않게 명시.
4. **Scope 분리**: SPL은 generic constraint conditioning, PCA는 specific to count aggregation but with atom generality.

본문 위치: Related Work §6 또는 §7 — Shukla 2023 단락 바로 다음.
부록 또는 footnote: SPL을 "if implemented for our count constraint" 가상 시나리오로 한 줄 코멘트 ("would require per-$K$ SDD compilation; we leave such a comparison to future work, as the practical gap from atom-shape recompilation makes the comparison axis distinct from our atomic-PMF algebra contribution.").

### 비-baseline 결정의 정당화 (reviewer rebuttal 대비)

reviewer가 "왜 SPL을 직접 baseline으로 안 비교했나"고 물을 가능성에 대비한 답변:

- **SPL은 count-WSL method가 아님.** Constraint conditioning framework로, count case는 SDD compilation을 통한 가능성으로만 존재.
- **이 논문의 contribution axis는 atom-shape 일반성** (binary→multi-class→signed→multiplicity의 algebraic unification). SPL을 SDD compile해서 비교하면 비교 axis가 "compilation cost vs no compilation"으로 다르게 정의됨 → A1 message 흐림.
- **Shukla 2023이 이미 SIMPLE Prop 1 (binary count DP)를 import**해 둔 게 우리의 직접 base. PCA = "SIMPLE의 count primitive를 atomic PMF의 conv로 generalize". SPL은 base lineage에 없음.

## 4. Multi-class scope의 정확한 경계

A1이 다루는 "multi-class"는 **ordinal counting variable**에 한정.

### 적용 가능 (ordinal sum well-defined)

- $z_i \in \{0, 1, \dots, K\}$로 표현되는 ordinal class — 합이 의미 있음.
  - MNIST-sum: $z_i$ = digit value.
  - SVHN-sum: 동일.
  - Multi-digit composite: UltraMNIST.
- Signed: $z_i \in \{-1, 0, +1\}$ (또는 offset). Atom support 길이 3.
- Multiplicity: $z_i \in \{0, m_i\}$. Atom 길이 $m_i + 1$, 0과 $m_i$에 spike. Multi-class의 trivial reparam.

### 적용 불가 (nominal — sum 정의 안 됨)

- $z_i \in \{$cat, dog, bird$\}$. 일반 multi-class classification.
- ImageNet-style 1000-class classification.
- CIFAR-10 raw labels (airplane, automobile, ..., truck — nominal).

### 본문 표기 규약

- 단순 "multi-class" 표현은 reviewer가 nominal로 받아들일 위험. 항상 **"multi-class ordinal counting"** 또는 **"ordinal multi-class"**로 명시.
- §3 도입에서 한 단락으로 명시: "We use 'multi-class' throughout to mean ordinal counting variables $z_i \in \{0,\dots,K\}$ where $\sum_i z_i$ has numeric meaning. Nominal multi-class targets (e.g., ImageNet) are out of scope, as the conv view requires the support set to admit a sum operation. We discuss this scope explicitly to prevent over-generalization of our claim."

## 5. Baseline 5종 + 제외 후보 사유

### 채택 (5종, MNIST-sum/SVHN-sum/UltraMNIST 공통 적용)

**1a. Mean-pool regression** — sanity floor
- per-instance regression head $\hat z_i \in \mathbb R$, bag prediction $\hat Y = \sum_i \hat z_i$. Loss = MAE/MSE.
- 분포 못 냄. PCA의 PMF/NLL 강점 살림.

**2a. PL-multiclass (Tsai 2020 일반화)** — Shukla narrative 정합
- per-instance categorical $\hat p_i \in \Delta^{K+1}$ → bag-level 평균 $\bar p = \frac{1}{N}\sum_i \hat p_i$ → ground-truth class proportion vector와 KL/CE.
- Shukla이 PL을 "averaged bag posterior approximation"으로 비판한 대상의 multi-class 버전. **Conv의 exact PMF를 직접 대비할 수 있는 가장 자연스러운 baseline.**

**2b. CLT/Gaussian approximation** — 새 비교축
- per-instance categorical $\hat p_i$로부터 instance mean $\mu_i$, variance $\sigma_i^2$ 계산.
- Bag sum $\hat Y \sim \mathcal N(\sum \mu_i, \sum \sigma_i^2)$로 근사. Loss: Gaussian NLL.
- **Shukla이 안 다룬 angle** — "exact discrete PMF vs Gaussian approximation". PMF/NLL 직접 비교 가능 (PCA와 metric 동치).

**3a. Attention pooling + multi-class head (Ilse 2018 adapted)** — 표준 MIL baseline
- per-instance feature $h_i$ → attention weight $a_i$ → bag embedding $z = \sum_i a_i h_i$ → classifier head outputs PMF over $\{0, \dots, NK\}$.
- Shukla baseline의 직접 일반화. Reviewer 친숙도 최대.

**3b. DeepSets (Zaheer 2017)** — Shukla이 안 다룬 standard set baseline
- per-instance encoder $\phi$ → permutation-invariant aggregation $\rho(\sum_i \phi(h_i))$ → bag head outputs PMF.
- Shukla이 비교 안 한 표준 set-aggregation 모델. 추가 가치.

### 제외

**Shukla DP를 multi-class로 일반화한 변종** — 의도적 제외
- 이유: multi-class DP를 직접 짜면 우리 conv와 algorithmic 등치. "DP의 trivial extension"으로 trivialize 위험.
- (B) framing에서는 "multi-class DP ≡ conv"라는 등치를 본문 short proposition으로 명시해서 contribution으로 전환 — baseline으로 비교하지 않음.

**SPL** — verdict (b), 위 §3 참조
- 이유: multi-class atomic PMF native 미지원, SDD compilation 부담. Related Work 단락으로만.

**Sampling-based (REINFORCE, Gumbel-softmax)** — Tier 4a 후보였으나 보류
- 이유: optional, scope 확장 우려. 시간 여유 있으면 부록에 포함.

**Set Transformer (Lee 2019)** — DeepSets로 충분
- 이유: 추가 backbone 종류는 implementation cost만 늘리고 contribution 강화 약함. DeepSets로 set-aggregation tier는 충분히 cover.

## 6. Metric — top-1 accuracy + MAE + NLL 동시 보고

이유 (대화 §a 응답에서 결정):
- **Top-1 accuracy**: 모든 method 공통 비교 (점 추정 비교, 공정성 보장).
- **MAE**: ordinal 거리감 반영 (1과 2 혼동 < 1과 50 혼동).
- **NLL**: PCA의 native 강점 (분포 quality). Mean-pool regression baseline은 제외 또는 fixed-variance Gaussian으로 NLL 계산.

각 metric별 모델별 적용 표:

| Method | Top-1 acc | MAE | NLL |
|---|---|---|---|
| 1a Mean-pool regression | ✓ (round) | ✓ | △ (Gaussian wrap 필요) |
| 2a PL-multiclass | ✓ (argmax bag prop) | ✓ | △ |
| 2b CLT Gaussian | ✓ (round mean) | ✓ | ✓ (Gaussian NLL) |
| 3a Attention pooling | ✓ (argmax PMF) | ✓ | ✓ |
| 3b DeepSets | ✓ (argmax PMF) | ✓ | ✓ |
| **PCA (ours)** | ✓ (argmax PMF) | ✓ (mode/expectation) | ✓ (exact PMF) |

NLL 비교는 분포를 native로 출력하는 method 간에만 (2b, 3a, 3b, PCA). 1a/2a는 점 추정만 하므로 NLL 비교 제외 또는 명시적으로 fixed-variance Gaussian wrap.

## 7. Dataset — 4개 채택 + CIFAR re-config 검토

### 채택 4개 (image-domain multi-class ordinal counting)

**MNIST-sum** — primary, 가장 단순
- Bag = MNIST 숫자 10장, label = $\sum$ ∈ [0, 90].
- 28×28 grayscale. Backbone: SmallCNN (B1 verification에서 사용한 ~206k 파라미터 그대로).
- Atom: $z_i \in \{0,\dots,9\}$, $K = 9$, atom 길이 10.

**SVHN-sum** — real-world digits
- Bag = SVHN crop 10장, label = $\sum$ ∈ [0, 90].
- 32×32 RGB, real photos. Backbone: 더 큰 CNN (~500k–1M 파라미터).
- 동일 ordinal $z_i$ 구조 → MNIST-sum과 직접 비교 가능.
- 이미 multi-class MIL 논문에서 SVHN을 majority-label/proportion 설정으로 사용 (arXiv:2403.13370). **Sum 형식은 우리가 처음 정의** — 새 task 정의 contribution.

**UltraMNIST** — scale stress
- 4000×4000 image 안에 3-5개 MNIST digit이 흩어짐, label = $\sum$ ∈ [0, 27].
- 28K+28K, public (Scientific Data 2024 / Kaggle competition).
- Bag size가 자연 가변 → PCA의 일반성 stress test.
- Backbone: detector-style 또는 patch-based encoder. 구현 부담은 MNIST/SVHN보다 큼.

**Binary backbone 검증 (이미 완료)** — B1 verification의 MNIST-MIL 결과 재사용
- Atomic PMF Bernoulli case ($K=1$, atom 길이 2) = Shukla DP와 등치.
- B1 verification에서 MNIST-MIL($N \in \{10, 50, 100\}$, NLL/EM 비교) 결과가 이미 존재. 그 NLL 결과가 곧 PCA binary case의 baseline + Shukla DP equivalence 검증.
- 추가 실험 불필요. A1 paper §4에 "binary case verification"으로 인용.

### CIFAR re-configuration 검토 — **stretch only, A1 main에는 미포함**

CIFAR-10 raw label은 nominal이라 sum이 정의 안 됨. Multi-class ordinal counting으로 가려면 다음 옵션 중 하나:

| Option | 설명 | 평가 |
|---|---|---|
| (a) Re-label by ordinal attribute | "leg count": airplane/car/ship/truck=0, bird=2, cat/deer/dog/frog/horse=4 → 3-class ordinal {0,2,4} | 매우 contrived. 사실상 binary counting (vehicle vs animal) + 동물 내 추가 group. K=2 effective. **Skip.** |
| (b) CIFAR-stack synthesis | 각 instance image = 캔버스에 $z_i \in \{0,\dots,K\}$ 개의 target-class 썸네일을 paste. Bag = $N$개 instance. | UltraMNIST의 CIFAR 버전. 합성 부담 + UltraMNIST와 redundant. **Skip unless UltraMNIST에서 fail.** |
| (c) CIFAR-binary-count | Bag = CIFAR 이미지 $N$개, instance label = "is cat?" 0/1. Bag = cat 개수. | Binary task → 우리 Bernoulli case. B1 verification의 binary 검증과 redundant. **Skip.** |
| (d) Mixed-class count | Bag = CIFAR 이미지 $N$개, instance label = K-way (예: animal 종 ordinal 매핑). Bag = $\sum$. | (a)와 동일 문제 + 매핑 임의성. **Skip.** |

**결정: A1 main 검증에서는 CIFAR 제외.** SVHN-sum + UltraMNIST가 이미 image complexity 한 단계 위 (real-world clutter, multi-digit composition)이고, CIFAR-stack은 UltraMNIST와 redundant.

본문 footnote 또는 부록 한 줄: "CIFAR-style natural image domains can be supported via synthetic bag construction (e.g., target-class thumbnail stacking) but are out of scope for the algorithmic verification, which is exercised on digit-domain ordinal counting tasks of progressively higher visual complexity (MNIST → SVHN → UltraMNIST)."

향후 reviewer가 CIFAR를 요구하면 rebuttal에서 CIFAR-stack으로 small-scale 추가 실험 가능 — 하지만 paper main에는 안 둠.

### 제외된 dataset 후보

- PANDA Gleason (medical) — Track 3 real-domain stretch 후보였으나 (D2)에서 제외 결정. "top-2 합" caveat과 WSI 처리 부담 때문.
- LIMUC, APTOS DR, OAI knee — per-image labeling, 합성 bag 필요 → MNIST-sum과 redundant.
- Galaxy Zoo, CBIS-DDSM, Crowd counting, COCO — 구조적 부적합.
