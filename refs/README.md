# Reference Materials

This directory is for read-only context: papers, reviewer comments, prior code,
and short notes that help position the CountMIL experiments.

Keep active implementation work in `src/`, `scripts/`, `tests/`, and `configs/`.
Keep generated experiment outputs in `results/`.

Recommended layout:

- `papers/`: PDFs, reviews, rebuttals, and paper-specific notes.
- `prior_code/`: previous repositories or baseline implementations used as references.
- `notes/`: lightweight synthesis notes, experiment matrices, and positioning notes.

Avoid storing large datasets or bulk experiment outputs here. Prefer small result
summaries, tables, or links/paths to larger artifacts.
