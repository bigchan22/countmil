\section{Convolutional bag prediction}
\label{sec:convolutional-bag-prediction}

\subsection{Aggregate likelihood}

The instance network and contribution map emit the atomic PMFs $d_i$ used in Definition~\ref{def:finite-support-aggregator}.
For one-dimensional contributions, this is a categorical distribution over a finite integer support:
\begin{equation}
  d_i(k) = p_\theta(z_i = k \mid x_i), \qquad k \in \{a,\ldots,b\}.
\end{equation}
The exact aggregate-label likelihood is \method{} applied to these atomic PMFs:
\begin{equation}
  p_\theta(Y=y \mid x_{1:n})
  =
  \mathsf{Agg}(d_1,\ldots,d_n)(y)
  =
  \left(d_1 * d_2 * \cdots * d_n\right)(y).
\end{equation}
Training minimizes the negative log likelihood
\begin{equation}
  \mathcal{L}_{\mathrm{agg}}(\theta)
  =
  -\log p_\theta(Y=y \mid x_{1:n}).
\end{equation}
The support of the aggregate PMF is finite and contiguous:
\begin{equation}
  \mathrm{supp}(Y) = \{na, na+1,\ldots, nb\}.
\end{equation}
Equivalently, if each atom has contiguous support size $S=b-a+1$, then the aggregate PMF has width $T=n(S-1)+1$ after shifting by $na$.
For scalar aggregate labels, all experiments evaluate the exact model-implied likelihood over this support; approximation enters through the neural instance model rather than through sampled latent assignments.

\paragraph{Two immediate consequences.}
First, when the atomic support is Bernoulli, the convolutional likelihood is exactly the coefficient of the polynomial $\prod_i((1-p_i)+p_it)$ and therefore recovers the standard count probability.
Second, for any finite support, the likelihood uses the entire induced aggregate distribution, not only the mean aggregate value.
Thus two instance predictors with the same expected sum can receive different likelihoods if they assign different probability mass to the observed aggregate.
This is the distinction exploited by the digit-sum and signed-count experiments.

\subsection{Training objective}

For each minibatch, the instance model and task-specific contribution map produce atomic PMFs for every instance in every bag.
\method{} then maps these atoms deterministically to an exact PMF over the observed aggregate label.
This separation makes the objective backbone-agnostic: an MLP, CNN, transformer, or pretrained image encoder can be used as long as it produces per-instance scores from which $\Phi$ can form the required finite-support PMFs.
It also makes the aggregate-supervision family modular: Bernoulli counts, signed counts, integer-valued sums, and one-vs-rest class counts use different kernels but the same likelihood rule.
The training loss is the negative log probability assigned to the observed aggregate,
\begin{equation}
  \mathcal{L}(\theta)
  =
  -\frac{1}{B}\sum_{b=1}^B
  \log
  \left(d_{b1} * \cdots * d_{bn_b}\right)(y_b).
\end{equation}
Gradients are backpropagated through \method{} into the instance network.
Instance labels are never used for training in the aggregate-supervision experiments; they are used only for evaluation of hidden instance recovery.
The expected-value baseline regresses only $\sum_i \mathbb{E}[z_i]$ to the observed aggregate, so it discards all information beyond the first moment.

Appendix~\ref{app:implementation-details} gives implementation details, including the classwise composite score used for one-vs-rest counts.

\subsection{Special cases}

Table~\ref{tab:method-kernels} summarizes the task-specific kernels; \method{} itself is unchanged.

\paragraph{Binary counts.}
A target concept gives hidden Bernoulli indicators $z_i$, and the observed label is $Y=\sum_i z_i$.
The kernel $[1-p_i,p_i]$ recovers the standard Bernoulli count likelihood, so this case is included as a connection to prior count-loss work.

\paragraph{Signed counts.}
With observed signs $s_i\in\{-1,+1\}$, target instances contribute $s_i$ and non-target instances contribute $0$, giving $Y_{\pm}=\sum_i s_i z_i$.
The signed kernels in Table~\ref{tab:method-kernels} model cancellation explicitly because many latent assignments can yield the same signed sum.

\paragraph{Integer-valued sums.}
For integer-valued labels $z_i\in\{0,\ldots,K-1\}$, the atomic kernel is the full categorical vector and the observed label is $Y_{\rm sum}=\sum_i z_i$.
The likelihood therefore compares the observed sum to the full convolved PMF rather than only to the expected sum $\sum_i\mathbb{E}[z_i]$.

\paragraph{Histograms.}
For multiclass count labels, we use a classwise composite likelihood over one-vs-rest Bernoulli counts: for each class $c$, \method{} scores the observed count $h_c=\sum_i z_{ic}$, and the loss averages over classes.
This is scalable, but it is not a full joint multiclass histogram model; it is closely related to the count-likelihood component of LLP-PVC.
The corresponding composite score is therefore not a normalized joint histogram probability.

\subsection{Computational backends}

All of the above objectives are one-dimensional convolutions over integer aggregate support.
If $m^{(i)}$ denotes the aggregate PMF after processing the first $i$ atoms, then
\begin{equation}
  m^{(i)}(s)
  =
  \sum_{r=a}^{b} m^{(i-1)}(s-r)d_i(r),
  \qquad
  m^{(0)}=\delta_0.
\end{equation}
This recurrence is the same probability law whether implemented as dynamic programming, shifted dense tensor accumulation, grouped convolution, or FFT polynomial multiplication.
The choice of backend is therefore computational rather than statistical: the likelihood being optimized is unchanged, but the hardware profile differs.
We use sequential convolution for moderate binary, signed, and integer-valued sum experiments; Shukla-style dynamic programming as a Bernoulli count baseline; grouped GPU convolution for signed Bernoulli groups; and a balanced FFT-tree backend for large classwise one-vs-rest count PMFs.
Further implementation details and backend complexity are given in Appendix~\ref{app:implementation-details}.
