\section{Additional Derivations}
\label{app:additional-derivations}

For binary count labels, let $p_i=p_\theta(z_i=1\mid x_i)$ and let the observed count be $y$.
Define the prefix distribution $F_i(k)=p_\theta(\sum_{j=1}^i z_j=k\mid x_{1:i})$ and suffix distribution $B_i(k)=p_\theta(\sum_{j=i}^n z_j=k\mid x_{i:n})$.
They are initialized by $F_0(0)=1$ and $B_{n+1}(0)=1$ and updated by the Bernoulli count recurrence
\begin{align}
F_i(k) &= (1-p_i)F_{i-1}(k)+p_iF_{i-1}(k-1),\\
B_i(k) &= (1-p_i)B_{i+1}(k)+p_iB_{i+1}(k-1).
\end{align}
Conditioning on the observed count gives
\begin{equation}
  p_\theta(z_i=1\mid \sum_j z_j=y,x_{1:n})
  =
  \frac{
    p_i\sum_k F_{i-1}(k)B_{i+1}(y-1-k)
  }{
    \sum_k F_{i-1}(k)\left[(1-p_i)B_{i+1}(y-k)+p_iB_{i+1}(y-1-k)\right]
  }.
\end{equation}
The denominator is the bag likelihood $p_\theta(Y=y\mid x_{1:n})$ written with instance $i$ separated out.
In the unsigned binary case, the resulting posterior marginals sum to the observed count up to numerical precision.

\section{Implementation Details}
\label{app:implementation-details}

All weak-supervision experiments sample bags on the fly rather than pregenerating fixed bag files.
Instance labels are used only for evaluation metrics such as hidden-instance AUC or hidden digit accuracy.
MNIST-family experiments use the project LeNet-style selector or digit classifier, Adam with learning rate $5\times 10^{-4}$, weight decay $10^{-4}$, and 50 epochs.
The main MNIST-family configurations use seeds $0,1,2$, test on 1000 sampled bags, and evaluate mean bag sizes 10 and 50 with standard deviations 2 and 10.

Histogram/PVC experiments treat each class count as a one-vs-rest Bernoulli count likelihood.
The MNIST histogram experiments use batch size 192 for large-bag configurations.
CIFAR-10 experiments use ResNet-18 backbones.
The from-scratch CIFAR settings use randomly initialized ResNet-18.
The pretrained PVC settings use ImageNet-pretrained ResNet-18 with random crop and horizontal flip augmentation, SGD with momentum 0.9, weight decay $10^{-4}$, learning rate $5\times 10^{-4}$, and a Ma-style cosine schedule for 500 epochs.
The pretrained CIFAR-10 analysis is limited to the evaluated $n=16$ and $n=64$ PVC settings.

\section{Additional Tables}
\label{app:additional-tables}

We also evaluated posterior-training variants for binary MNIST-Bags, including hard and tempered posterior objectives.
These variants did not reliably improve the negative-log-likelihood result, so the main method treats posterior marginals as an inference and diagnostic tool rather than as the central training objective.
The main text reports aggregate means, and seed counts are shown for comparisons evaluated with fewer than three seeds.
